# CogA library source

The library is dependency-free and contains the typed offline catalog model plus its deterministic validator.

- [RepositoryCatalog.cs](RepositoryCatalog.cs) — model types and repository identity parsing.
- [RepositoryCatalog.md](RepositoryCatalog.md) — companion documentation and class card.
- [CatalogValidator.cs](CatalogValidator.cs) — validation rules.
- [CatalogValidator.md](CatalogValidator.md) — companion documentation and class card.
- [Catalog UML](../../docs/UML/RepositoryCatalogUML.md) — source-derived model diagram and use cases.

The code does not call GitHub, dispatch workflows, handle credentials, or render a GUI.

# CiAi.CogA — Repository Catalog

**Mission:** typed, offline-first repository catalog and directed relationship model.

Read [the inter-repository model](https://github.com/TrentBest/TheSingularityWorkshop.CiAi/blob/development/docs/INTER_REPOSITORY_MODEL.md) and [Cog assignments](https://github.com/TrentBest/TheSingularityWorkshop.CiAi/blob/development/docs/COG_ASSIGNMENTS.md). Model capabilities/relationships such as provider, consumer, request sender, result receiver, build executor, coordinator, observer, policy authority, and presentation adapter. Test malformed identities, duplicate IDs, invalid edges, unknown capabilities, and incompatible versions.

No GitHub transport, credentials, dispatch, or GUI. Work only on development; do not edit siblings, master, or publish. Inspect APIs before reuse. Deliver tests, README, source-derived UML, readiness percentage, and evidence.

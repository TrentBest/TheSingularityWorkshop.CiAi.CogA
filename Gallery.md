# CogA Gallery

CogA is a small, dependency-free CiAi control-plane component. It makes one responsibility explicit and testable instead of hiding policy, identity, correlation, or lifecycle assumptions in coordinator code.

## See it in a minute

```bash
dotnet run --project tests/TheSingularityWorkshop.CiAi.CogA.ContractTests --configuration Release
```
